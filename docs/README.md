# Tài liệu dự án vlxd

Repo hiện ở giai đoạn plan/hướng dẫn. Chỉ giữ tài liệu có giá trị quyết định hoặc yêu cầu sản phẩm.

## Tài liệu yêu cầu

- `requirements/role-management.md` — role, title, user, permission matrix định hướng.
- `requirements/service-plans.md` — gói dịch vụ Free/Standard/Premium/Enterprise.
- `requirements/i18n.md` — song ngữ Việt / Anh, ưu tiên tiếng Việt.

## Tài liệu sẽ bổ sung sau

- `decision-backlog.md` — quyết định còn mở.
- `adr/` — quyết định kiến trúc khó đảo ngược.
- `architecture/` — sơ đồ kiến trúc khi bắt đầu scaffold.

## Nguyên tắc dọn docs

- Xóa HTML/CSV/export tạm nếu không còn là nguồn sự thật.
- Nội dung quan trọng phải được chuẩn hóa thành Markdown trong `docs/requirements`, `docs/architecture`, hoặc ADR.
- Không để nhiều bản mô tả cùng một yêu cầu gây mâu thuẫn.
